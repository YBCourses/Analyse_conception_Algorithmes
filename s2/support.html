1La mémoire en C

Variable, adresse, valeur

Une variable est une case de la mémoire qui a un nom, une valeur et une adresse. L’adresse est le numéro de la case : elle ne change jamais pendant la vie de la variable. Un int occupe 4 octets : les adresses de variables voisines sont donc espacées de 4.
int main(void) {
    int a = 5;          /* a : case n° 100, valeur 5  */
    int b = 7;          /* b : case n° 104, valeur 7  */
    int c = a + b;      /* c : case n° 108, valeur 12 */
    a = 100;            /* la valeur change, le numéro de case jamais */
    return 0;
}

Les numéros de cases sont ici des nombres simples pour faciliter l’explication. Le TP vous fera observer les vrais numéros, affichés en hexadécimal.

Les variables locales

Une variable locale est une variable déclarée à l’intérieur d’une fonction. Elle naît quand le programme exécute sa déclaration et meurt quand la fonction se termine : sa case est rendue et son contenu est perdu. Les variables locales sont rangées dans la zone appelée la pile, gérée automatiquement.
void compter(void) {
    int x = 10;    /* x naît ici */
}                  /* x meurt ici */

int main(void) {
    int a = 5;     /* a naît ici */
    compter();
    return 0;
}                  /* a meurt ici */

Chaque appel de fonction dispose de son propre espace de variables locales : pendant que compter s’exécute, la pile contient a (de main) puis x (de compter). À la fin de compter, x disparaît.

Le pointeur

Un pointeur est une variable dont la valeur est l’adresse d’une autre case, c’est-à-dire un numéro. On dit qu’il désigne cette case, et on le dessine par une flèche : la flèche n’est que le dessin du numéro rangé dans le pointeur.

NULL

NULL est une valeur de pointeur qui signifie « ne désigne aucune case ». Suivre un pointeur NULL (écrire *p) fait planter le programme : on teste if (p != NULL) avant. NULL marque aussi la fin d’une liste chaînée.

malloc, free et sizeof

  • sizeof(T) : le nombre d’octets d’un type T (sizeof(int) vaut 4).
  • malloc(n) : réserve un bloc de n octets dans le tas et renvoie son adresse, ou NULL si la mémoire manque.
  • free(p) : rend au système le bloc désigné par p.
int *p = malloc(sizeof(int));   /* p désigne un bloc de 4 octets du tas */
*p = 42;                        /* on écrit dans le bloc */
free(p);                        /* on rend le bloc : il n'est plus à nous */
p = NULL;                       /* bonne habitude : plus d'adresse périmée */
Règle d’or : chaque malloc doit avoir son free, une seule fois.

Une fonction reçoit des copies

En C, chaque paramètre est copié à l’appel. Pour qu’une fonction modifie une variable de l’appelant, on lui passe son adresse.

Par valeur : ne modifie pas a
void f(int x) {
    x = 9;
}

int main(void) {
    int a = 5;
    f(a);           /* a vaut toujours 5 */
    return 0;
}
Par adresse : modifie a
void g(int *y) {
    *y = 9;
}

int main(void) {
    int a = 5;
    g(&a);          /* a vaut maintenant 9 */
    return 0;
}

Structures et pointeurs vers structures

struct Noeud {
    int valeur;
    struct Noeud *suivant;     /* adresse d'un autre nœud */
};

Avec une variable n, on écrit n.valeur. Avec un pointeur p, on écrit p->valeur, qui équivaut à (*p).valeur.

Pointeur de pointeur : plusieurs étoiles

Un pointeur est une variable comme les autres : il a lui-même une adresse. On peut donc ranger l’adresse d’un pointeur dans un autre pointeur. Une étoile de plus dans la déclaration = un niveau de flèche de plus.

int main(void) {
    int a = 5;          /* a  : case n° 100, valeur 5   */
    int *p = &a;        /* p  : case n° 104, valeur 100 */
    int **pp = &p;      /* pp : case n° 112, valeur 104 */
    **pp = 9;           /* suit deux flèches : a vaut 9  */
    *pp = NULL;         /* *pp est p : p vaut NULL       */
    return 0;
}

À quoi servent deux étoiles : modifier un pointeur dans une fonction

Une fonction qui doit modifier un pointeur de l’appelant reçoit l’adresse de ce pointeur, donc un pointeur de pointeur. Sinon, elle ne travaille que sur une copie.

Ne marche pas : q est une copie de p
void alloue(int *q) {
    q = malloc(sizeof(int));
    *q = 7;
}

int main(void) {
    int *p = NULL;
    alloue(p);      /* p vaut toujours NULL ;
                       le bloc est perdu (fuite) */
    return 0;
}
Marche : pp contient l’adresse de p
void alloue(int **pp) {
    *pp = malloc(sizeof(int));
    **pp = 7;
}

int main(void) {
    int *p = NULL;
    alloue(&p);     /* p désigne maintenant le bloc */
    return 0;
}

C’est exactement le cas de la tête d’une liste : Noeud *tete est un pointeur, donc une fonction d’insertion qui doit le modifier reçoit un Noeud **tete et on l’appelle avec inserer(&tete, 5). Dans la fonction, *tete est la variable de l’appelant.

Les matrices : un tableau de tableaux

Une matrice de 2 lignes et 3 colonnes peut se construire dans le tas comme un tableau de 2 pointeurs, chacun désignant une ligne de 3 entiers. Le type de m est int **.

int main(void) {
    int **m = malloc(2 * sizeof(int *));   /* tableau de 2 pointeurs  */
    m[0] = malloc(3 * sizeof(int));        /* ligne 0 : 3 entiers     */
    m[1] = malloc(3 * sizeof(int));        /* ligne 1 : 3 entiers     */
    m[1][2] = 6;                           /* ligne 1, colonne 2      */
    free(m[0]);                            /* on libère les lignes... */
    free(m[1]);
    free(m);                               /* ...puis le tableau      */
    return 0;
}
ExpressionTypeSe lit
mint **l’adresse du tableau de pointeurs
m[1]int *l’adresse de la ligne 1 (une étoile de moins)
m[1][2]intla case n° 2 de la ligne 1 (encore une étoile de moins)

m[1][2] s’écrit aussi *(*(m + 1) + 2) : deux étoiles, donc deux flèches suivies. Les crochets sont une écriture plus lisible. On libère toujours les lignes avant le tableau de pointeurs : sinon on perdrait les adresses des lignes (fuite mémoire). Au-delà de deux étoiles (int ***, un tableau de matrices), le principe reste le même : une étoile par niveau de flèche.

2Tableau ou liste ?

Un tableau donne un accès direct : t[i] coûte une opération, car l’adresse se calcule (début + i × taille). Mais sa taille est fixe, et insérer au début oblige à décaler les n éléments : Θ(n).

ExemplePour insérer 9 au début de [4, 7, 1, 8, 3], il faut faire t[5] ← t[4], t[4] ← t[3], …, t[1] ← t[0] (5 décalages), puis t[0] ← 9. Pour n = 1 000 000, c’est un million de décalages à chaque insertion.

Idée : comme dans une chasse au trésor où chaque indice donne l’emplacement du suivant, on met dans chaque élément l’adresse de l’élément suivant. Les éléments n’ont plus besoin d’être voisins en mémoire : c’est la liste chaînée.

3La liste chaînée

Un nœud est un bloc du tas qui contient une valeur et l’adresse du nœud suivant. Une liste chaînée est une suite de nœuds reliés ainsi. La variable tete désigne le premier ; le dernier nœud pointe vers NULL.

Les nœuds sont dispersés dans le tas : leurs adresses ne se suivent pas, seules les flèches les relient. La tête est la seule entrée de la liste.

Parcourir

courant ← tete
tant que courant ≠ NULL faire
    afficher(courant.valeur)
    courant ← courant.suivant

On visite chaque nœud une fois : Θ(n).

Insérer au début

n ← nouveau nœud
n.valeur ← 5
n.suivant ← tete        // 1. le nouveau nœud désigne l'ancien premier
tete ← n                // 2. la tête désigne le nouveau nœud
Si on inverse les deux dernières lignes, tete ← n d’abord, plus personne ne désigne l’ancienne liste : elle est perdue, et n.suivant ← tete fait pointer le nœud sur lui-même. L’ordre des affectations décide si la liste survit.

Quatre instructions, quelle que soit la longueur : Θ(1). C’est la réponse à la question d’échauffement : tableau Θ(n), liste Θ(1).

Insérer à la fin

courant ← tete
tant que courant.suivant ≠ NULL faire
    courant ← courant.suivant
n ← nouveau nœud (valeur 5, suivant NULL)
courant.suivant ← n

Il faut parcourir la liste pour trouver le dernier nœud : Θ(n). Avec une variable queue qui désigne en permanence le dernier nœud, l’insertion en fin devient Θ(1) (à condition de mettre queue à jour).

Rechercher

Parcours avec test courant.valeur = x : c’est la recherche séquentielle, Θ(n). La recherche dichotomique est impossible : elle exige d’aller directement au milieu, et une liste n’offre pas d’accès direct.

Supprimer

// supprimer un nœud de valeur x (cas général)
precedent ← tete ;  courant ← tete.suivant
tant que courant.valeur ≠ x faire
    precedent ← courant ;  courant ← courant.suivant
precedent.suivant ← courant.suivant     // on court-circuite courant
libérer(courant)

// cas particulier : supprimer le premier nœud
temp ← tete
tete ← tete.suivant
libérer(temp)

Trouver le nœud coûte Θ(n), le retirer une fois trouvé coûte Θ(1). Dans le cas du premier nœud, on garde son adresse dans temp avant de changer tete, sinon on le perdrait sans pouvoir le libérer.

Libérer toute la liste

courant ← tete
tant que courant ≠ NULL faire
    suivant ← courant.suivant      // garder le suivant AVANT de libérer
    libérer(courant)
    courant ← suivant
tete ← NULL

Aucune structure n’est « meilleure » : on choisit selon les opérations les plus fréquentes.

Variantes

  • Liste doublement chaînée : chaque nœud connaît son précédent et son suivant. On parcourt dans les deux sens et on supprime un nœud sans parcours préalable, au prix d’un pointeur de plus par nœud.
  • Liste circulaire : le dernier nœud désigne de nouveau le premier. Utile pour tourner en boucle (tourniquet). Il n’y a plus de NULL : il faut un autre critère d’arrêt.

4La pile

Une pile est une structure où l’on n’ajoute et ne retire que par le dessus : le dernier entré est le premier sorti (LIFO, last in, first out). Exemples : annuler (Ctrl+Z), bouton « retour » d’un navigateur, pile d’assiettes.
OpérationEffetCoût
empiler(x)pose x au sommetΘ(1)
dépiler()retire et renvoie l’élément du sommetΘ(1)
sommet()montre le sommet sans le retirerΘ(1)
est_vide()vrai si la pile est videΘ(1)

Dépiler une pile vide est une erreur : on teste est_vide() avant. Une pile faite avec un tableau de taille fixe peut aussi être pleine.

Deux implémentations

Avec un tableau
empiler(x):
    sommet ← sommet + 1
    t[sommet] ← x
dépiler():
    x ← t[sommet]
    sommet ← sommet - 1
    retourner x
Avec une liste chaînée
empiler(x):
    insérer x en tête
dépiler():
    x ← tete.valeur
    supprimer la tête
    retourner x

Dans les deux cas, toutes les opérations coûtent Θ(1). Le tableau est limité en taille ; la liste n’a pas de limite et réutilise l’insertion et la suppression en tête.

Application 1 : parenthèses bien formées

La dernière parenthèse ouverte doit être la première fermée. Algorithme :

  1. ouvrante ( [ { : on l’empile ;
  2. fermante ) ] } : si la pile est vide, c’est mal parenthésé ; sinon on dépile et on vérifie la correspondance ;
  3. à la fin, la pile doit être vide.
ExpressionVerdictPourquoi
{ [ ( ) ] }correctchaque fermante rencontre son ouvrante, pile vide à la fin
( [ ) ]incorrectla fermante ) trouve [ au sommet
( ( )incorrectil reste une ouvrante dans la pile à la fin
( ) )incorrectfermante alors que la pile est vide

Chaque caractère est traité une fois, avec des opérations en Θ(1) : le coût total est Θ(n).

Application 2 : la notation postfixe

Dans la notation postfixe, l’opérateur est écrit après ses deux opérandes : plus de parenthèses ni de priorités.

HabituelPostfixe
3 + 43 4 +
(3 + 4) × 23 4 + 2 *
3 + 4 × 23 4 2 * +
5 + (1 + 2) × 4 − 35 1 2 + 4 * + 3 -

Évaluation : un nombre s’empile ; un opérateur dépile deux nombres (b puis a), calcule a op b et empile le résultat ; à la fin, il reste un seul nombre, le résultat. Exemple pour 3 4 + 2 * : pile 3 ; pile 3, 4 ; « + » donne 7 ; pile 7, 2 ; « * » donne 14.

Application 3 : la pile d’appels

Chaque appel de fonction en cours est une fiche posée sur une pile (séance 1). On empile à chaque appel, on dépile à chaque retour. Toute fonction récursive peut être réécrite sans récursion avec une pile explicite.

5La file

Une file est une structure où l’on ajoute à la fin et où l’on retire au début : le premier entré est le premier sorti (FIFO, first in, first out). Exemples : file d’attente à un guichet, travaux d’une imprimante, paquets d’un routeur.
OpérationEffetCoût visé
enfiler(x)ajoute x à la finΘ(1)
défiler()retire et renvoie l’élément du débutΘ(1)
premier()montre l’élément du début sans le retirerΘ(1)
est_vide()vrai si la file est videΘ(1)

Défiler une file vide est une erreur : on teste est_vide() avant. Le défi est de garder Θ(1) pour les deux opérations principales, alors qu’on travaille aux deux extrémités.

Pile contre file

On ajoute 1, 2, 3 puis on retire trois fois. Avec une pile (LIFO), les valeurs sortent dans l’ordre 3, 2, 1. Avec une file (FIFO), elles sortent dans l’ordre 1, 2, 3. Choisir entre les deux, c’est choisir dans quel ordre on traite les éléments en attente : le plus récent d’abord, ou le plus ancien.

Avec un tableau : le piège du décalage

Première idée : le premier élément est toujours dans la case 0. Pour défiler, on retire la case 0 et on décale tout le monde d’une case : n − 1 décalages, donc Θ(n). C’est le défaut du chapitre 2.

Meilleure idée : ne rien décaler. On garde une variable début, l’indice du premier élément. Défiler consiste seulement à avancer début d’une case. Mais on finit par atteindre la fin du tableau alors qu’il reste de la place au début : on revient alors à la case 0. C’est le tableau circulaire.

Le tableau circulaire

Trois variables : le tableau t de N cases, début (indice du premier élément) et taille (nombre d’éléments présents). Pour avancer d’une case en bouclant, on écrit (i + 1) mod N : avec N = 6, après la case 5 on retombe sur la case 0 (mod est le reste de la division, % en C).

enfiler(x):
    t[(début + taille) mod N] ← x
    taille ← taille + 1
défiler():
    x ← t[début]
    début ← (début + 1) mod N
    taille ← taille - 1
    retourner x

Aucun décalage : enfiler et défiler coûtent Θ(1). La file est pleine quand taille = N et vide quand taille = 0. Exemple : N = 5, début = 3, taille = 4 : les éléments sont dans les cases 3, 4, 0, 1 ; le prochain enfiler écrit dans la case (3 + 4) mod 5 = 2.

Avec une liste chaînée : tete et queue

Retirer au début d’une liste est facile (suppression en tête, Θ(1)). Ajouter à la fin ne l’est pas : avec seulement tete, il faut parcourir toute la liste, donc Θ(n). L’astuce est de garder une seconde variable queue qui désigne le dernier nœud : on accroche le nouveau nœud directement au bout.

Enfiler
enfiler(x):
    n ← nouveau nœud
    n.valeur ← x
    n.suivant ← NULL
    si queue = NULL alors   // file vide
        tete ← n
    sinon
        queue.suivant ← n
    queue ← n
Défiler
défiler():
    temp ← tete
    x ← temp.valeur
    tete ← tete.suivant
    si tete = NULL alors    // file devenue vide
        queue ← NULL
    libérer(temp)
    retourner x

Les deux opérations coûtent Θ(1). Attention au cas particulier de la file vide : à l’enfilage dans une file vide, tete et queue désignent le même nœud ; au défilage du dernier nœud, il faut remettre queue à NULL, sinon elle désignerait un bloc libéré (pointeur pendant).

À quoi sert une file ?

  • Système d’exploitation : les tâches prêtes attendent dans une file et passent chacune à leur tour sur le processeur (tourniquet).
  • Réseau : un routeur met les paquets en file ; si elle est pleine, les nouveaux paquets sont perdus.
  • Algorithmes : le parcours en largeur d’un graphe (séance 6) utilise une file pour garder l’ordre de visite.

Pour la liste chaînée et la pile : la version C (celle du TP), puis une version Python simplifiée. En Python, le ramasse-miettes libère les nœuds inutilisés : pas de free.

Nœud, création et insertion en tête

typedef struct Noeud {
    int valeur;
    struct Noeud *suivant;
} Noeud;

Noeud *creer_noeud(int v) {
    Noeud *n = (Noeud *)malloc(sizeof(Noeud));
    n->valeur = v;
    n->suivant = NULL;
    return n;
}

void inserer_tete(Noeud **tete, int v) {
    Noeud *n = creer_noeud(v);
    n->suivant = *tete;   /* 1. relier à l'ancien premier */
    *tete = n;            /* 2. changer la tête */
}

Parcours, recherche, insertion en fin

C
void afficher(Noeud *tete) {
    Noeud *c;
    for (c = tete; c != NULL; c = c->suivant)
        printf("%d -> ", c->valeur);
    printf("NULL\n");
}

Noeud *rechercher(Noeud *tete, int x) {
    while (tete != NULL && tete->valeur != x)
        tete = tete->suivant;
    return tete;             /* NULL si absent */
}

void inserer_fin(Noeud **tete, int v) {
    Noeud *n = creer_noeud(v), *c;
    if (*tete == NULL) { *tete = n; return; }
    c = *tete;
    while (c->suivant != NULL) c = c->suivant;
    c->suivant = n;
}

Suppression et libération

C
int supprimer(Noeud **tete, int x) {
    Noeud *prec = NULL, *cour = *tete;
    while (cour != NULL && cour->valeur != x) {
        prec = cour;
        cour = cour->suivant;
    }
    if (cour == NULL) return 0;          /* absent */
    if (prec == NULL) *tete = cour->suivant;
    else prec->suivant = cour->suivant;
    free(cour);
    return 1;
}

void liberer(Noeud **tete) {
    Noeud *cour = *tete, *suiv;
    while (cour != NULL) {
        suiv = cour->suivant;   /* AVANT free */
        free(cour);
        cour = suiv;
    }
    *tete = NULL;
}
Python
def supprimer(tete, x):

Matrice allouée dynamiquement

C
int **creer_matrice(int lignes, int colonnes) {
    int **m = (int **)malloc(lignes * sizeof(int *));
    int i;
    for (i = 0; i < lignes; i++)
        m[i] = (int *)malloc(colonnes * sizeof(int));
    return m;
}

void liberer_matrice(int **m, int lignes) {
    int i;
    for (i = 0; i < lignes; i++) free(m[i]);   /* les lignes d'abord */
    free(m);                                   /* puis le tableau */
}

Pile (tableau) et parenthèses

C
#define MAX 1000
char pile[MAX];
int sommet = -1;

void empiler(char c) { pile[++sommet] = c; }
char depiler(void)   { return pile[sommet--]; }
int  est_vide(void)  { return sommet < 0; }

int bien_parenthesee(const char *s) {
    int i;
    char c, o;
    sommet = -1;
    for (i = 0; s[i] != '\0'; i++) {
        c = s[i];
        if (c == '(' || c == '[' || c == '{') empiler(c);
        else if (c == ')' || c == ']' || c == '}') {
            if (est_vide()) return 0;
            o = depiler();
            if ((c == ')' && o != '(') ||
                (c == ']' && o != '[') ||
                (c == '}' && o != '{')) return 0;
        }
    }
    return est_vide();
}
Python
def bien_parenthesee(s):
    pile = []                        # une liste sert de pile
    paires = {")": "(", "]": "[", "}": "{"}
    for c in s:
        if c in "([{":
            pile.append(c)           # empiler
        elif c in ")]}":
            if not pile:             # pile vide ?
                return False
            if pile.pop() != paires[c]:   # dépiler
                return False
    return not pile


def evaluer_postfixe(expression):
    pile = []
    for t in expression.split():
        if t in "+-*/":
            b, a = pile.pop(), pile.pop()
            pile.append({"+": a + b, "-": a - b,
                         "*": a * b, "/": a // b}[t])
        else:
            pile.append(int(t))
    return pile[0]

File (tableau circulaire et liste chaînée)

C : tableau circulaire
#define N 8
int t[N];
int debut = 0, taille = 0;

int enfiler(int x) {
    if (taille == N) return 0;        /* file pleine */
    t[(debut + taille) % N] = x;
    taille++;
    return 1;
}

int defiler(int *x) {
    if (taille == 0) return 0;        /* file vide */
    *x = t[debut];
    debut = (debut + 1) % N;
    taille--;
    return 1;
}
C : liste avec tete et queue
typedef struct Noeud {
    int valeur;
    struct Noeud *suivant;
} Noeud;

typedef struct {
    Noeud *tete;
    Noeud *queue;
} File;

void file_init(File *f) { f->tete = NULL; f->queue = NULL; }
int  file_est_vide(const File *f) { return f->tete == NULL; }

void enfiler(File *f, int x) {
    Noeud *n = malloc(sizeof(Noeud));
    n->valeur = x;
    n->suivant = NULL;
    if (f->queue == NULL) f->tete = n;      /* file vide */
    else f->queue->suivant = n;
    f->queue = n;
}

int defiler(File *f) {                /* file non vide */
    Noeud *temp = f->tete;
    int x = temp->valeur;
    f->tete = temp->suivant;
    if (f->tete == NULL) f->queue = NULL;
    free(temp);
    return x;
}

7Exercices corrigés

Cherchez d’abord seul, puis ouvrez la solution.

Mémoire

Exercice 1

int a = 3, b = 4;
int *p = &a;
int *q = &b;
*p = *q;
q = p;
*q = 0;
Que valent a et b à la fin ? Vers quoi pointe q ?
Solution
*p = *q : a prend la valeur de b, soit 4. q = p : q désigne maintenant a. *q = 0 : a vaut 0. Résultat : a = 0, b = 4, et q désigne a.

Exercice 2

int *p;
*p = 10;
Quel est le problème ?
Solution
p n’est pas initialisé : il contient une adresse au hasard. Écrire dedans plante ou abîme la mémoire. Il fallait p = malloc(sizeof(int)) ou p = &a.

Exercice 3

Noeud *n = malloc(sizeof(Noeud));
n->valeur = 1;
free(n);
printf("%d", n->valeur);
Quel est le problème ?
Solution
Après free(n), n est un pointeur pendant : le bloc ne nous appartient plus. Mettre n = NULL après le free évite l’erreur, ou au moins la rend visible (plantage immédiat plutôt que bug sournois).

Exercice 11 (pointeurs de pointeurs)

int a = 1, b = 2;
int *p = &a;
int **pp = &p;
**pp = 10;
*pp = &b;
**pp = 20;
Que valent a et b à la fin ? Vers quoi pointe p ?
Solution
**pp = 10 : pp désigne p, qui désigne a : a vaut 10. *pp = &b : on range l’adresse de b dans p (à travers pp) : p désigne maintenant b. **pp = 20 : pp désigne p, qui désigne b : b vaut 20. Résultat : a = 10, b = 20, et p désigne b.

Exercice 12 (matrice)

Écrivez en C une fonction qui construit une matrice 3 × 4 remplie de zéros, la remplit avec m[i][j] = i * 4 + j, puis la libère complètement. Combien de malloc et combien de free ?
Solution
Un malloc pour le tableau de 3 pointeurs, plus 3 pour les lignes : 4 malloc. Il faut donc 4 free : 3 pour les lignes, puis 1 pour le tableau de pointeurs, dans cet ordre. Voir creer_matrice et liberer_matrice dans le code de référence ; la valeur m[2][3] est 11.

Listes et piles

Exercice 4

La liste est 2 → 5 → 8. On fait inserer_tete(1) puis supprimer(5). Quelle liste obtient-on ? Quel est le coût de chaque opération ?
Solution
Après l’insertion : 1 → 2 → 5 → 8 (Θ(1)). Après la suppression de 5 : 1 → 2 → 8 (Θ(n) pour trouver 5, puis Θ(1) pour le retirer).

Exercice 5

Pile vide. On fait : empiler 1, empiler 2, empiler 3, dépiler, empiler 4, dépiler, dépiler. Quelles valeurs sortent, dans quel ordre ? Que reste-t-il ?
Solution
Sorties : 3, 4, 2. Il reste 1 dans la pile.

Exercice 6

Évaluez en postfixe : 2 3 4 * + puis 6 2 / 3 -.
Solution
2 3 4 * + : 3 × 4 = 12, puis 2 + 12 = 14. 6 2 / 3 - : 6 ÷ 2 = 3, puis 3 − 3 = 0.

Exercice 7 (supplémentaire)

Quelle est la complexité de l’insertion à la fin d’une liste chaînée de n nœuds, sans puis avec une variable queue ?
Solution
Sans queue : il faut parcourir les n − 1 premiers nœuds, donc Θ(n). Avec queue : on écrit directement queue.suivant ← n puis queue ← n, donc Θ(1).

Exercice 8 (supplémentaire)

Écrivez en pseudo-code l’inversion d’une liste chaînée en un seul parcours, sans créer de nouveaux nœuds.
Solution
precedent ← NULL
courant ← tete
tant que courant ≠ NULL faire
    suivant ← courant.suivant      // garder la suite
    courant.suivant ← precedent    // retourner la flèche
    precedent ← courant
    courant ← suivant
tete ← precedent
Un seul parcours : Θ(n). À chaque tour, on retourne une flèche ; sans la variable suivant, on perdrait la suite de la liste.

Exercice 9 (supplémentaire)

Évaluez 5 1 2 + 4 * + 3 - et donnez l’expression usuelle correspondante.
Solution
1 + 2 = 3 ; 3 × 4 = 12 ; 5 + 12 = 17 ; 17 − 3 = 14. Expression usuelle : 5 + (1 + 2) × 4 − 3.

Exercice 10 (supplémentaire)

L’expression { [ ( ] ) } est-elle bien parenthésée ? Dessinez la pile à chaque étape.
Solution
Pile après chaque caractère : { ; { [ ; { [ ( ; puis on lit ] : on dépile ( qui ne correspond pas à ]. Mal parenthésée.

Files

Exercice 13 (files)

File vide. On fait : enfiler 1, enfiler 2, enfiler 3, défiler, enfiler 4, défiler, défiler. Quelles valeurs sortent, dans quel ordre ? Que reste-t-il ? Comparez avec l’exercice 5.
Solution
Sorties : 1, 2, 3. Il reste 4 dans la file. Avec une pile, les mêmes opérations donnaient 3, 4, 2 et il restait 1 : l’ordre de sortie est inversé.

Exercice 14 (tableau circulaire)

Tableau circulaire de N = 5 cases, début = 3, taille = 4. Dans quelles cases se trouvent les éléments ? Où enfiler écrit-il ? Que vaut début après un défiler ?
Solution
Éléments dans les cases 3, 4, 0, 1 (on boucle après la case 4). enfiler écrit dans la case (3 + 4) mod 5 = 2. Après un défiler : début = (3 + 1) mod 5 = 4 et taille = 3.

Exercice 15 (supplémentaire : liste avec queue)

Une file est une liste chaînée avec tete et queue. Elle contient un seul élément. On appelle défiler. Que doivent valoir tete et queue ensuite ? Que se passe-t-il si on oublie de modifier queue ?
Solution
La file est vide : tete = NULL et queue = NULL. Si on oublie queue ← NULL, queue désigne un bloc déjà libéré (pointeur pendant) : le prochain enfiler écrirait dans ce bloc libéré au lieu de créer une file propre.
