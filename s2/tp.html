Pour démarrer

Vous allez construire une liste chaînée en C, mesurer ce qu’elle apporte face à un tableau, puis écrire une pile qui vérifie des parenthèses et une file.

Télécharger tp2.c

gcc tp2.c -o tp2 -O0 -Wall
./tp2            # sous Windows : tp2.exe

Le fichier contient la structure Noeud, des fonctions fournies (creer_noeud, afficher, longueur, rechercher, une pile de caractères, le type File) et six fonctions à écrire, marquées TODO 1 à TODO 6. Les fonctions partie1() à partie5() font les expériences. Au départ, seule la partie 1 est active : dans main, vous activerez les suivantes une par une.

  1. Comparez l’adresse de a et la valeur de p. Que constatez-vous, et pourquoi ?

Partie 5 · Une file 10 min

Une file est une structure « premier entré, premier sorti ». Vous la construisez avec la liste chaînée, en gardant deux pointeurs : tete (le premier, celui qui sortira) et queue (le dernier arrivé). La structure File et son affichage sont fournis.

5.1 · TODO 5 Écrivez file_enfiler(File *f, int v) : ajoute v à la fin, sans parcourir la liste. Pensez au cas particulier de la file vide (alors tete doit aussi changer).
5.2 · TODO 6 Écrivez file_defiler(File *f, int *x) : retire le premier nœud, range sa valeur dans *x et renvoie 1 ; renvoie 0 si la file est vide. Si la file devient vide, queue doit être remis à NULL. N’oubliez pas nb_free++.

Questions

  1. Dans quel ordre sortent les valeurs ? Que donnerait la même suite d’opérations avec la pile de la partie 4 ?
  2. Quelle est la complexité de file_enfiler et de file_defiler ? Que deviendrait celle de file_enfiler si la structure n’avait que tete, sans queue ?

Aide

Le programme plante (erreur de segmentation)
Cherchez un pointeur suivi alors qu’il vaut NULL, ou un Noeud ** utilisé sans *. Ajoutez des printf pour afficher où le programme s’arrête.
La liste affichée est vide ou incomplète après l’insertion
Vérifiez l’ordre de vos trois instructions : le nouveau nœud doit désigner l’ancienne tête avant que *tete change. Vérifiez aussi que vous écrivez bien *tete = n et non tete = n.
Les compteurs malloc et free sont différents
Un nœud n’a pas été libéré. Vérifiez que supprimer et liberer font chacune nb_free++ à chaque free.
La suppression du premier nœud ne marche pas
Quand prec vaut NULL, il n’y a pas de nœud avant : c’est *tete qui doit changer, pas un champ suivant.
Mes temps de la liste valent tous 0
Le chronomètre est trop peu précis pour une durée très courte. La fonction répète déjà la construction ; si besoin, augmentez le nombre de répétitions dans chrono_liste (variable reps).
Le tableau met trop de temps
Seuls les rapports comptent. Si une mesure dépasse 30 secondes, retirez la plus grande valeur de n dans partie3.
La file perd des éléments, ou le programme plante après le dernier défilage
Vérifiez les deux cas particuliers : file vide à l’enfilage (tete doit changer aussi) et file devenue vide au défilage (queue doit valoir NULL). Dans file_enfiler, ne parcourez jamais la liste : queue désigne déjà le dernier nœud.
Le bouton d’export ne télécharge rien
Utilisez « Copier le JSON », collez le contenu dans un fichier texte nommé TP2_NOM_Prenom.json, puis déposez ce fichier.
